# 자동차 독립 4회 실행 결과 업데이트

기존 1회와 추가 3회를 모두 포함했습니다. test에서 한 번이라도 성공한 정책은 4개 중 1개, test 1,024회 모두 성공한 정책은 1개입니다. 이는 **네 번의 모델 응답에서 관측한 결과**이며 Astra의 일반적인 성공 확률 추정으로 해석하지 않습니다.

| 실행 | 편집문 | 변경 가중치 | search 성공 / 256 | test 성공 / 1,024 | 출력 토큰 | Astra 시간(초) |
|---|---:|---:|---:|---:|---:|---:|
| 1 | 1/1 | 1 | 0 | 0 | 3,914 | 199.9 |
| 2 | 55/55 | 6958 | 0 | 0 | 13,370 | 504.1 |
| 3 | 55/55 | 6703 | 256 | 1024 | 16,095 | 642.0 |
| 4 | 24/24 | 1912 | 0 | 0 | 3,513 | 174.9 |

네 번 모두 같은 원문 프롬프트, gpt-6-astra, effort high, tools-off, 새 대화, 답변 1회입니다. 프롬프트 SHA256 동일과 서로 다른 대화 ID를 확인했습니다. 평가 결과나 이전 답변을 Astra에게 제공하지 않았습니다. Search seed는 0부터 255, test는 100000부터 101023으로 모든 실행에 동일합니다. 편집문은 반올림된 원본 망에 매번 새로 적용했습니다.

새 성공 실행의 MP4가 있으면 `car_rN_before_after.mp4` 이름입니다. 모두 seed 0 고정의 실제 상태 영상이며, seed 0 결과가 그 정책의 전체 성공률을 대신하지 않습니다. `car_published_reference.mp4`는 계속 공개된 원문 가중치의 영상이며 이번 새 실행 결과가 아닙니다.

추가 실행의 짧은 진단은 해당 `car_rN_answer.txt`의 최종 답변에서 인용할 수 있습니다. 비공개 추론 과정은 전달 묶음에 넣지 않았습니다. 출력 토큰에 추론 토큰이 포함됩니다.

## 영상과 자막

- `car_r3_before_after.mp4`: 이번 **실행 3**의 새 Astra 가중치. 수정 전 경사에서 정지, 수정 후 후진과 도움닫기를 거쳐 점프 성공. 같은 seed 0, 72스텝에 목표 도달. 1920×1080, 30fps, 11.53초.
- `car_new_astra.mp4`: 실행 1의 실패 영상. 0/1,024 결과에 해당하며, seed 0은 적색 접촉으로 실패. 실행 1의 test 실패 중 85개는 적색 접촉, 939개는 시간 초과.
- `car_published_reference.mp4`: 공개된 **원문 가중치**의 성공 영상. 이번 새 Astra 실행으로 소개하면 안 됩니다. 원문 기록은 1,024/1,024이고, 이번 평가기에서 별도 확인한 것은 32/32입니다.
- `breakout.mp4`: 새 Astra Breakout 플레이, seed 0, 71점, 1,174스텝. 960×1080, 30fps, 41.13초. 전체 1,000회 평균은 416.797 ± 6.901 SE입니다. 원문 Astra 기록 517.4, 공개 원문 가중치의 이번 평가 502.880 ± 7.747 SE, 원문 PPO 기록 25.3과 구분해야 합니다.

영상은 실제 시뮬레이터 상태를 그린 무음 편집 재료입니다. 종료한 자동차는 마지막 프레임을 유지하고, 256개 상태 뒤에 3초 정지 화면을 붙였습니다. 물리 frame skip은 2이고 영상은 30fps입니다. 자막의 에피소드 점수와 전체 평가 평균을 혼동하지 마세요.

권장 표현: “같은 프롬프트로 자동차 가중치를 네 번 독립 작성했다. 그중 한 정책은 별도 평가 1,024회 모두 성공했고, 나머지 세 정책은 모두 실패했다.” 이것을 Astra의 일반 성공 확률이 25%라는 주장으로 확대하지 않습니다.

## 설명과 실행 증거

`car_r3_quote.txt`에는 성공 정책의 설명 원문과 한국어 요약이 있습니다. `car_rN_answer.txt`에는 각 실행의 최종 답변이, `car_four_attempts.csv/json`에는 네 번의 전체 결과가 있습니다. `*_run_summary.json`은 프롬프트 해시·사용량·도구 감사이며 `*_scores.json`은 측정 결과입니다.

`*_execution_log.png`는 실제 실행 메타데이터와 최종 답변을 시각화한 이미지로, 실제 화면 녹화나 터미널 스크린샷은 아닙니다. 이미지에 이 사실을 표시했습니다. 실제 화면 녹화는 수집하지 못했습니다.

Breakout의 Astra 실행은 xhigh, 820.8초, 출력 25,938토큰(그중 추론 20,646). 204개 편집문을 적용했고 20,486개 중 1,248개 가중치가 0이 아닙니다. 자동차 네 번은 모두 high입니다.

원문의 정확한 난수열은 공개되지 않아 새로운 고정 난수열로 평가했습니다. 4개 정책은 같은 seed 집합을 공유합니다. 공개 원문 가중치로 평가기를 확인했으며, 프롬프트는 매번 byte-for-byte 동일합니다. 실패한 실행도 모두 보고했고, 평가 결과를 Astra에 피드백하지 않았습니다.

원본 로그와 가중치, 재현 코드는 별도 보존됩니다. 이 묶음에는 내부 절대 경로와 인증 정보가 없습니다.

## 동일 test seed의 수정 전 추가 측정

수정 전 반올림 PPO 망도 성공 정책과 같은 test seed 100000부터 101023으로 1,024회 평가했습니다. 성공 0/1,024, 적색 접촉 0, 시간 초과 1024, invalid 0. CPU JAX, frame skip 2, 최대 256스텝, 같은 행동 샘플링을 사용했습니다. 따라서 실행 3과는 **수정 전 0/1,024 → 수정 후 1,024/1,024**의 동일 seed 비교가 가능합니다. 근거 파일은 car_base_test_scores.json과 car_r3_scores.json입니다.
